## 2. Design System & Typography Compliance
- **Color Reference**: Luxury portfolio dark theme (`#050608` deep dark background, `#0A0D12` card surfaces, `#10151D` elevated panels, `#1677FF` electric blue accent, `#10B981` emerald success, `#F59E0B` amber warning, `#F43F5E` rose alert).
- **Three Strict Font Families**:
  1. `Playfair Display`: Selected premium display headers and institute branding.
  2. `Raleway`: Primary navigation, labels, forms, and interface body text.
  3. `Inter`: Marks, grades, numbers, timers, tabular metrics, and dense data.
- **Microinteractions**: Smooth hover transitions, interactive radio option buttons, animated loaders, copy-to-clipboard badges.
